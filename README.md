# 制度智能审查系统

## 项目简介

本项目为软件工程专业学位研究生课题，拟设计并实现一个基于大语言模型与检索增强生成（RAG）的制度智能审查系统。

系统计划覆盖制度管理、文档结构化、制度关系维护、混合检索、四维智能审查、证据校验、报告生成、人工复核与审计留痕等功能。

## 当前阶段

项目处于研究设计与需求分析阶段。当前仓库包含脱敏后的选题报告及论文工作计划，后续将逐步补充需求、架构、代码、测试和实验材料。

公开版本的项目背景参见：[项目选题报告（脱敏版）](docs/项目选题报告（脱敏版）.md)。

## 数据安全

- 不得提交真实密钥、访问令牌或密码。
- 未脱敏的制度文件和客户数据不得提交到仓库。
- 原始数据应存放在被 `.gitignore` 排除的 `data/raw/` 或 `data/private/` 目录。
- 公开仓库不得包含个人信息、客户名称或内部业务材料。

## 计划模块

1. 制度文件上传与管理
2. Word/PDF 文档解析与条款结构化
3. 制度版本及关系管理
4. 关键词与向量混合检索
5. 语义分歧、规则匹配、制度冲突和一致性审查
6. 证据校验与结构化审查报告
7. 人工复核、权限控制与操作留痕
8. 实验评测与论文材料
