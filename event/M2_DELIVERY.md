# M2 功能与页面原型交付说明

## 1. 交付结果

M2 已在 `event/frontend/` 完成。该目录包含一套可以本地运行的 Vue 3 前端原型，使用模拟数据展示全部已确认的 M2 页面与交互。

| M2 范围 | 页面或入口 | 实现状态 |
|---|---|---|
| 登录与角色区分 | 登录页、审查人员区、系统管理区 | 已完成 |
| 制度管理 | 制度库、新增/编辑弹窗、业务删除 | 已完成 |
| 制度详情 | 基本信息、版本、解析条款、关系、历史审查 | 已完成 |

## 3. 需求约束落实

- 审查人员和系统管理员使用不同功能区。
- 管理员区域不提供审查报告内容入口。
- 上传、删除、关系维护三项操作根据当前账号权限控制。
- 制度状态只展示“生效中”和“已失效”。
- 原文位置使用标题层级与段落序号，不使用页码。
- 审查记录没有用户填写的任务名称，也没有持久化任务状态。
- 只有制度冲突维度展示对比制度原文。
- 四个审查维度使用不同字段结构。
- 证据不足的问题显示“证据不足，请人工判断”；证据充分时不显示额外标签。
- 问题支持采纳修改建议、忽略和补充处理意见，并展示处理留痕。
- 管理员操作历史只包含制度新增、删除和恢复。

## 4. 验证结果

- `pnpm build`：通过。
- TypeScript 类型检查：通过。
- 浏览器检查：登录页、制度库、审查记录、四维报告、管理员人员权限页通过。
- 页面控制台错误检查：未发现错误。

## 5. 原型边界

当前实现属于 M2，不会把后续里程碑提前伪装为已完成：

- 文件上传、解析、候选召回和智能审查均使用页面模拟。
- 数据只保存在当前浏览器内存中，刷新后恢复初始模拟数据。
- 后端鉴权、数据库、文件持久化、SSE 和国产大模型 API 尚未接入。
- 真实制度切分规则、完整规则审查内容和字段最终校验仍遵循现有阻塞项。

## 6. 本地启动

进入 `event/frontend/` 后运行：

```bash
pnpm install
pnpm dev
```

演示账号和具体功能说明见 `event/frontend/README.md`。
