# 制度智能审查系统 · M3 前端

本目录是制度智能审查系统的 Vue 前端，技术栈为 Vue 3、TypeScript、Vite、Element Plus、Vue Router 和 Pinia。M3 的登录、权限、基础数据、制度、版本、关系、删除恢复和操作历史已接入真实后端；文件解析、候选检索、审查任务和智能报告仍保留为后续里程碑的演示原型。

## 启动

请先按照上级目录的 `README.md` 启动后端，然后运行：

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

|---|---|---|
| `reviewer` | 审查人员 | 拥有上传、删除、关系管理三项权限 |

登录页也提供三个一键演示入口。

## 页面覆盖

- 制度库：真实检索、新增、编辑和业务删除。
- 制度详情：真实基本信息、版本和制度关系；条款解析与历史审查仍是原型数据。
- 关系与基础数据：真实部门、分类、一级—二级单位隶属和制度关系。
- 发起审查：来源、指定条款、维度、冲突候选条款、当次运行反馈。
- 审查记录：自动编号、所选范围和报告入口；没有任务状态字段或筛选器。
- 四维报告：语义分歧、规则匹配、制度冲突、一致性四种独立结构及人工处理留痕。
- 人员与权限：真实账号启停、密码重置和三项权限。
- 删除恢复与历史：真实制度恢复，以及新增、删除、恢复记录的查看和删除。

## M3 边界

- 不执行真实制度文件上传、条款解析、候选检索或大模型审查。
- 不固化尚未确认的字段必填、唯一性、长度和日期约束。
- 不包含公开注册、OA/统一登录、审批流程、OCR、表格解析或视觉排版审查。
- 原文位置只使用文件/标题层级/段落信息，不使用页码。
- 审查执行反馈只在当前页面显示，不作为历史任务状态保存。
