# M3 基础业务 API

后端覆盖 M3 的账号权限、组织分类、单位、制度、版本、删除恢复、操作历史与制度关系。

## API 分组

- `/api/v1/auth`：登录、当前用户、退出。
- `/api/v1/regulations`：制度检索、详情、新增编辑、删除、版本、关系和关系建议。
- `/api/v1/master-data`：部门、分类和一级/二级单位。
- `/api/v1/admin`：审查人员、三项权限、制度恢复和操作历史。

登录成功后，服务端通过 HttpOnly Cookie 保存随机会话凭据；密码使用 Argon2 哈希。密码复杂度、会话期限、失败锁定等参数仍等待非功能需求确认。

## 自动关系

- 同部门制度实时展示双向“关联”。
- 一级单位制度与所属二级单位制度实时展示“上位/下位”。
- 手工关系只保存一条有向记录，读取目标制度时自动展示反向关系。
- 疑似引用建议需要人工确认后才转为正式关系。
